Like all other xo-server plugins, it can be configured directly via

### Zabbix Trapper Setup with PSK

This plugin uses Zabbix's **Trapper** mechanism to send backup health status with **PSK (Pre-Shared Key)** authentication for secure communication.

#### Prerequisites

1. A Zabbix server (version 5.0 or higher recommended)
2. A Zabbix host named `XOA` (or custom name)
3. PSK configured on the Zabbix server
4. PSK identity and PSK value
5. Network access from Xen Orchestra to Zabbix Trapper port (default: 10051)

#### Zabbix Configuration

##### 1. Generate PSK

Generate a secure PSK (Pre-Shared Key) for authentication:

```bash
# Generate a random 32-byte PSK (64 hex characters)
openssl rand -hex 32 > /etc/zabbix/zabbix_agentd.psk
chmod 600 /etc/zabbix/zabbix_agentd.psk
```

Example PSK file content (hex-encoded):
```
a1b2c3d4e5f6789012345678901234567890123456789012345678901234567890
```

##### 2. Configure Zabbix Server for PSK

Configure your Zabbix server to accept PSK connections:

1. Edit `/etc/zabbix/zabbix_server.conf`
2. Set or verify these parameters:
   ```
   # TLSCAFile=/path/to/ca_file
   # TLSCertFile=/path/to/cert_file
   # TLSKeyFile=/path/to/key_file
   TLSPSKFile=/etc/zabbix/zabbix_agentd.psk
   TLSPSKIdentity=PSK_SENDER_001
   ```
3. Restart Zabbix server:
   ```bash
   systemctl restart zabbix-server
   ```

##### 3. Create the XOA Host

Create a host to receive backup status updates:

1. Log in to Zabbix as Administrator
2. Navigate to **Configuration > Hosts**
3. Click **Create host**
4. Fill in:
   - **Host name**: `XOA` (must match XO configuration)
   - **Visible name**: `Xen Orchestra Appliance`
   - **Host groups**: Select an existing group (e.g., "Infrastructure")
   - **Interfaces**: Add a dummy Agent interface
5. Go to **Encryption** tab:
   - **Connections to host**: PSK
   - **PSK identity**: `PSK_SENDER_001` (must match server config)
   - **PSK value**: Your PSK hex string
6. Click **Add**

##### 4. Create Trapper Items

Create items for each backup status key you want to send. The key names will be configured when other plugins use this transport.

1. In the XOA host, navigate to the **Items** tab
2. Click **Create item**
3. Fill in:
   - **Name**: `Backup Health`
   - **Key**: Any key name (e.g., `backup.health` - will be set by calling plugin)
   - **Type**: **Trapper**
   - **Type of information**: **Numeric (unsigned)**
   - **Update interval**: `0` (not used for Trapper)
4. Click **Add**

> **Note**: The exact item keys will be determined by other plugins that use this transport plugin.

##### 5. (Optional) Create Triggers

Create triggers to alert on backup failures:

1. Go to the XOA host and select **Triggers**
2. Click **Create trigger**
3. Example:
   - **Name**: `Backup Status Critical`
   - **Expression**: `last(/XOA/backup.health)=2`
   - **Severity**: `High`
   - **Description**: `Latest backup run has a critical status`
4. Click **Add**

#### XO Plugin Configuration

In the Xen Orchestra web interface, configure:

- **Zabbix Server**: The hostname or IP address of your Zabbix server
  - Examples: `zabbix.example.com`, `192.168.1.100`
- **Port**: The Zabbix Trapper port (default: `10051`)
  - Only change if you've configured a non-standard port in Zabbix
- **Host**: The Zabbix host name (default: `XOA`)
  - Must match the host name you created in Zabbix
- **PSK Identity**: The PSK identity configured in Zabbix
  - Example: `PSK_SENDER_001`
  - Must match the `TLSPSKIdentity` in Zabbix server config
- **PSK Value**: The PSK as a hex string (without file path)
  - Example: `a1b2c3d4e5f6789012345678901234567890123456789012345678901234567890`
  - This is the actual PSK value, not a file path
  - Get it from: `cat /etc/zabbix/zabbix_agentd.psk` (on Zabbix server)

#### Status Values

The plugin sends these numeric values to Zabbix items:

| Status | Value | Meaning |
|--------|-------|---------|
| OK | 0 | Last backup successful |
| WARNING | 1 | Backup completed with warnings |
| CRITICAL | 2 | Backup failed |

#### Testing the Plugin

1. Navigate to the transport-zabbix plugin settings in Xen Orchestra
2. Click **Test**
3. The plugin will attempt to connect to the Zabbix server
4. If successful, you'll see a confirmation message
5. Check in Zabbix **Monitoring > Hosts > XOA** to verify connectivity

#### Troubleshooting

**"Connection refused" or "Cannot connect"**
- Verify the server hostname/IP is correct and reachable
- Ensure the Trapper port (10051) is open between XO and Zabbix
- Check firewall rules: `telnet zabbix.example.com 10051`
- Verify Zabbix server is running: `systemctl status zabbix-server`

**"PSK value error"**
- Ensure the PSK value is hex-encoded (0-9, a-f characters only)
- Verify the PSK value length is correct (typically 64 hex characters = 32 bytes)
- Check that you pasted the entire PSK value without spaces or newlines
- Example: `a1b2c3d4e5f6789012345678901234567890123456789012345678901234567890`

**"PSK identity mismatch"**
- Verify the PSK identity matches exactly in both Zabbix and XO config
- Check Zabbix server logs for PSK errors: `tail -f /var/log/zabbix/zabbix_server.log`

**Data not appearing in Zabbix**
- Verify the Trapper item exists in the XOA host with matching key
- Check Zabbix **Monitoring > Hosts > XOA > Latest data** for received values
- View Zabbix logs: `tail -f /var/log/zabbix/zabbix_server.log`

**PSK value error**
- Ensure the PSK file contains only hex characters (no spaces, newlines)
- The PSK should be 64 hex characters (32 bytes): `openssl rand -hex 32`
- Example valid PSK: `a1b2c3d4e5f6789012345678901234567890123456789012345678901234567890`
